## Project Overview

This project develops a Comparative AI Governance Framework Evaluation Model to support responsible AI adoption in Australian higher education institutions.

The project evaluates internationally recognised AI governance frameworks including:

- NIST AI Risk Management Framework
- ISO/IEC 42001
- European Union AI Act
- Australian Government AI Guidance

The outcome is a decision-support model that helps universities choose an AI governance framework based on governance maturity, ethics, transparency, accountability, privacy, and regulatory compliance.

---

## Project Objectives

- Review existing AI governance frameworks.
- Compare governance models.
- Develop evaluation criteria.
- Build a decision-support framework.
- Validate the model using university AI scenarios.
