# Project Charter

## Project Title

Comparative AI Governance Framework Evaluation Model for Responsible AI Adoption in Australian Higher Education Institutions

---

## Background

Australian universities increasingly adopt Artificial Intelligence for teaching, research, and administration. Selecting an appropriate AI governance framework remains challenging because multiple international standards exist with different objectives.

---

## Aim

Develop a comparative evaluation model that assists universities in selecting suitable AI governance frameworks.

---

## Objectives

1. Review AI governance frameworks.
2. Develop evaluation criteria.
3. Compare governance frameworks.
4. Validate using university scenarios.
5. Provide governance recommendations.

---

## Deliverables

- Literature Review
- Comparative Framework Matrix
- Evaluation Model
- Risk Register
- Final Report
